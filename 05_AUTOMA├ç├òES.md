# 🔔 AUTOMAÇÕES: LEMBRETES + DOCUMENTOS + BASE DE CLIENTES

**Versão:** 1.0  
**Para:** Configurar UM única vez e esquecer  
**Economia de tempo:** +10h/mês

---

## 🎯 O que vamos automatizar

1. **Lembretes para VOCÊ** — Não perca nenhuma ação
2. **Lembretes para CLIENTE** — Ele fica informado
3. **Geração de documentos** — Cria automaticamente
4. **Base de dados** — Histórico de cada cliente

---

## 📅 LEMBRETES PARA VOCÊ

**Configure esses lembretes em seu calendário (Google, Outlook, Telefone)**

### 1️⃣ Follow-up proposta (Dia 3 após envio)

**O que fazer:**
- Enviar mensagem WhatsApp: "Oi, recebeu proposta? Ficou com dúvida?"
- Se não responder: deixar para dia 7

**Configure no seu calendário como:**
- Título: "Follow-up proposta - [CLIENTE]"
- Repetição: Uma vez (3 dias após envio)
- Notificação: 09:30 (sua hora produtiva)

---

### 2️⃣ Follow-up proposta (Dia 7 após envio)

**O que fazer:**
- WhatsApp: "Oi, confirmando que você recebeu a proposta. Tem dúvida em algum plano? Me responde aqui!"
- Se não responder: deixar para dia 14

**Configure:**
- Título: "Follow-up proposta 2 - [CLIENTE]"
- Repetição: Uma vez (7 dias após)
- Notificação: 09:30

---

### 3️⃣ Último follow-up proposta (Dia 14 após envio)

**O que fazer:**
- WhatsApp: "Oi! Essa é a última vez. Se quiser mesmo, me responde. Senão, fico esperando!"
- Se não responder: arquivar como "não convertido"

**Configure:**
- Título: "Follow-up proposta 3 (final) - [CLIENTE]"
- Repetição: Uma vez (14 dias após)
- Notificação: 09:30

---

### 4️⃣ Checagem de documentos (Dia 10 após onboarding)

**O que fazer:**
- Ligar ou mandar WhatsApp se faltam documentos
- "Oi, já conseguiu juntar tudo? Se tá faltando algo, me fala"

**Configure:**
- Título: "Checagem docs - [CLIENTE]"
- Repetição: Uma vez (10 dias após início onboarding)
- Notificação: 09:30

---

### 5️⃣ Envio de Dashboard (Dia 25 todo mês)

**O que fazer:**
- Preparar dashboard mensal
- Enviar para todos os clientes ativos
- Conferir se chegou

**Configure:**
- Título: "Enviar dashboards (todos os clientes)"
- Repetição: Todo mês, dia 25
- Notificação: 09:00

---

### 6️⃣ Alerta de limite anual (Quinzenal após dia 20 do mês)

**O que fazer:**
- Se cliente próximo de R$ 81.915, avisar
- "Ó, você tá chegando no limite!"

**Configure:**
- Título: "Revisar limites MEI (clientes próximos)"
- Repetição: Todo mês, dia 20 e 5
- Notificação: 10:00

## 💾 BASE DE DADOS DE CLIENTES

**Use este template para controlar tudo. Copie para Excel/Google Sheets.**

### Tabela Principal

| Nº | NOME | CPF | EMAIL | WHATSAPP | PLANO | VALOR | DATA INÍCIO | CNPJ | STATUS | ÚLTIM CONTATO | NOTAS |
|----|------|-----|-------|----------|-------|-------|------------|------|--------|----------------|-------|
| 1 | Maicon Zaccaron | XXX.XXX.XXX-XX | maicon@email.com | (XX) XXXXX-XXXX | Prof | 197 | 20/09/2026 | Pendente | Onboarding | 20/09 | Marmiteiro |
| 2 | [NOME] | | | | | | | | | | |

---

### Campos importantes:

- **Nº:** Número sequencial
- **NOME:** Nome completo do cliente
- **CPF:** CPF para referência
- **EMAIL:** Email de contato
- **WHATSAPP:** Com DDD
- **PLANO:** Essencial/Profissional/Premium
- **VALOR:** Quanto você vai ganhar/mês
- **DATA INÍCIO:** Quando começou
- **CNPJ:** CNPJ do MEI (quando ativar)
- **STATUS:** Prospect/Onboarding/Ativo/Inativo
- **ÚLTIM CONTATO:** Data do último contato
- **NOTAS:** Observações importantes

### Status possíveis:

- **Prospect:** Recebeu proposta, aguardando resposta
- **Onboarding:** Aceitou, coletando documentos
- **Ativo:** MEI ativado, acompanhando
- **Inativo:** Encerrou contrato
- **Não convertido:** Rejeitou proposta

---

## 📊 COMO USAR A BASE (Passo a passo)

**Ao receber uma proposta:**
1. Adicione linha na tabela
2. Preencha dados básicos
3. Deixe CNPJ em branco (ainda não tem)
4. Status = "Prospect"

**Ao cliente aceitar:**
1. Mude status para "Onboarding"
2. Registre data de início

**Quando MEI ativar:**
1. Preencha CNPJ
2. Mude status para "Ativo"

**Se cliente cancelar:**
1. Mude status para "Inativo"
2. Deixe tudo registrado (histórico)

**Se cliente não responder:**
1. Deixe 30 dias
2. Mude status para "Não convertido"
3. Guarde para prospectar novamente em 6 meses

## ⚙️ COMO CONFIGURAR AUTOMAÇÕES (Passo a passo)

### Google Calendar (Recomendado)

1. Abra Google Calendar
2. Clique em "Criar"
3. Preencha:
   - Título: "Follow-up proposta - [CLIENTE]"
   - Data: [DATA PROPOSTA + 3 DIAS]
   - Horário: 09:30
   - Notificação: 15 min antes
4. Descrição: "Enviar WhatsApp: Recebeu proposta?"
5. Clique "Salvar"

**Repita para cada lembrete** (follow-up 7 dias, 14 dias, etc)

---

### Outlook (Se usar)

1. Abra Outlook
2. Clique em "Novo evento"
3. Preencha o que é pedido
4. Marque "Lembrete" (15 min antes)
5. Clique "Salvar"

---

### Telegram/WhatsApp (Se tiver bot)

Se seu WhatsApp tem automação:

1. Configure mensagens automáticas
2. Dia 1: "Bem-vindo! Checklist enviado"
3. Dia 3: "Recebeu checklist? Me envia docs"
4. Dia 10: "Tá faltando documento, me manda"
